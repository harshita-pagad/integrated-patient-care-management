## 🌟 Overview

**Integrated Patient Care Management System (IPCMS)** is a web-based hospital management interface designed to bring important patient-care activities together in one platform.

The system provides a clean and interactive dashboard for managing patients, appointments, doctors, prescriptions, billing, emergency cases, and discharge information.

This project currently focuses on the **frontend implementation** using HTML, CSS, and JavaScript.

---

## ✨ Features

### 🔐 Role-Based Access

Different hospital roles are provided:

- 👨‍⚕️ Doctor
- 👩‍⚕️ Nurse
- 🧑‍💼 Receptionist
- 👨‍💼 Administrator

The interface demonstrates role-based restrictions for important operations.

---

### 📊 Hospital Dashboard

The dashboard provides an overview of:

- Total Patients
- Active Patients
- Available Beds
- Appointments
- Emergency Cases
- Pending Bills
- System Status
- Recent Notifications

---

### 👥 Patient Management

Patient management includes:

- Patient registration
- Patient ID
- Patient name
- Age
- Gender
- Blood group
- Phone number
- Diagnosis
- Bed category
- Attending doctor
- Patient directory
- Patient search

---

### 📅 Appointment Management

The appointment module allows users to:

- Schedule appointments
- Select doctors
- Select appointment date
- Select appointment time
- Add appointment reason
- View appointment records

---

### 👨‍⚕️ Doctor Management

The system contains doctor profile cards displaying:

- Doctor photograph
- Doctor name
- Specialization
- Qualifications
- Experience
- Appointment option

---

### 💊 Prescription Management

Doctors can manage prescription information such as:

- Patient ID
- Medicine
- Dosage
- Duration

Prescription modification is restricted to authorized roles in the frontend demonstration.

---

### 🚑 Emergency Care

Emergency management includes:

- Emergency patient registration
- Patient age
- Priority level
- Department
- Symptoms
- Emergency case tracking

Priority levels include:

- 🔴 Critical
- 🟠 Urgent
- 🟢 Normal

---

### 💰 Billing & Invoice

The billing module provides:

- Bed charges
- Doctor consultation charges
- Laboratory charges
- Automatic total calculation
- Invoice generation
- Print invoice option

---

### 📋 Patient Discharge

The discharge module includes:

- Patient ID
- Discharge date
- Final diagnosis
- Discharge instructions
- Follow-up date
- Discharge summary
- Printable discharge report

---

### 🖨️ Printing

Important reports can be printed directly from the browser.

Examples:

- 🧾 Invoice
- 📋 Discharge Summary
- 📑 Administrative Report

---

### 📑 Administrative Reports

The reporting section provides an overview of:

- Registered patients
- Appointments
- Emergency cases

Reports can also be printed.
